# Verificación de identidad en India

La API de Verificación de Identidad de Verifik te permite autenticar votantes en India usando datos electorales oficiales de la **Comisión Electoral de India (ECI)**. Consulta la **información de nombre** vinculada a un **EPIC** (número de *Elector's Photo Identity Card*) para flujos de KYC, onboarding o cumplimiento que requieran comprobar que un Voter ID devuelve datos de nombre coherentes con el padrón.

Diseñamos esta integración para empresas que necesitan corroborar identidad electoral de forma rápida, segura y automatizada dentro de programas más amplios de KYC y prevención de fraude.

## ¿Qué valida esta API?

Nuestra API se conecta a fuentes electorales oficiales para devolver:

- **Estructura del nombre del votante**: Nombre y apellidos (incl. variantes en escritura local cuando el origen las expone).
- **Nombre completo y familiar**: Campos adecuados para mostrar o comparar en alfabeto latino y en escritura local.
- **Coincidencia con EPIC**: El **EPIC de 10 caracteres** (letras y números) debe ser reconocado para devolver registro asociado.

Al verificar estos datos, puedes confirmar que el Voter ID corresponde a registros electorales válidos y reducir el riesgo de suplantación y fraude.

## Referencia de la API

### Endpoint

```
GET https://api.verifik.co/v2/in/epic
```

Envía una solicitud **GET** con el EPIC en el parámetro de consulta `documentNumber`. El servicio devuelve campos de nombre estructurados, valores opcionales en escritura local y un bloque **signature** de Verifik en caso de éxito.

### Headers

| Nombre          | Valor              |
| --------------- | ------------------ |
| Content-Type    | `application/json` |
| Authorization   | `Bearer <token>`   |

### Parámetros

| Nombre           | Tipo   | Requerido | Descripción                                                                 | Ejemplo     |
| ---------------- | ------ | --------- | --------------------------------------------------------------------------- | ----------- |
| `documentNumber` | string | **Sí**    | EPIC / Voter ID. Debe tener **exactamente 10 caracteres** (alfanumérico).   | `IHM2796746` |

### Notas

- `documentNumber` debe tener **exactamente 10 caracteres**; longitud o formato inválidos pueden devolver `409`.
- Los datos se obtienen **a través de Verifik**; la cobertura depende de la disponibilidad de la ECI para el EPIC consultado.
- Para **mesa y lugar de votación**, usa el endpoint complementario [**India — EPIC: información de votación y mesa**](/verifik-es/legal/votacion-eci-epic) (`GET /v2/in/epic/votacion`).

## Casos de uso comunes

- **Programas KYC e identidad** que necesitan corroborar un Voter ID con nombre y familiar devueltos.
- **Servicios gubernamentales y ciudadanos** que deben verificar un EPIC antes de emitir credenciales o acceso.
- **Fintech y cumplimiento** donde la verificación electoral forma parte de una estrategia más amplia de riesgo y fraude.

## Fuentes oficiales y confiabilidad

Verifik enruta las solicitudes a fuentes electorales confiables para que recibas datos coherentes con la búsqueda publicada por la ECI. Todas las llamadas usan TLS en tránsito; trata los EPIC como **datos personales sensibles** en tus políticas de registro y almacenamiento.

## Beneficios clave

- **Integración simple**: Un GET con `documentNumber` y el header estándar `Authorization`.
- **Respuesta estructurada**: Arrays de nombre y campos en escritura local cuando el origen los provee.
- **Certificación Verifik**: Cada respuesta exitosa puede incluir un bloque `signature` de Verifik para auditoría.

## Cumplimiento y seguridad

Usa solo HTTPS (la URL anterior está protegida con TLS). Almacena tokens de forma segura, rota claves API y sigue las normas de protección de datos de tu jurisdicción para datos electorales e identidad. La plataforma de Verifik está diseñada para acceso de alta disponibilidad y monitoreado.
