### 端点

```
PUT https://api.verifik.co/v2/phone-validations
```

此端点验证在 App Registration（onboarding）过程中发送到用户手机号码的一次性密码（OTP）。它确保用户提供的 OTP 正确，并相应更新验证状态。此路由专为处于 App Registration 流程中的用户设计。

:::warning
验证 `App Registration Phone Validations` 时应使用的 JWT 令牌来自创建 `App Registration` 时返回的令牌。您必须使用创建 [App Registration](https://docs.verifik.co/resources/app-registrations/create-an-app-registration) 时返回的令牌来验证此请求。
:::

### 请求头

| 名称 | 值 |
| --- | --- |
| Content-Type | `application/json` |
| Authorization | `Bearer <token>` |

### 参数

| 名称 | 类型 | 必需 | 说明 |
| --- | --- | --- | --- |
| `phone` | string | 是 | 创建手机验证时使用的手机号码。处理过程中会自动移除空格 |
| `countryCode` | string | 是 | 手机号码的国家代码，格式为 `+XXX`（例如巴拿马为 `+507`，美国为 `+1`）。必须匹配 `+` 后跟 1 到 3 位数字的格式 |
| `otp` | number | 是 | 发送到用户手机号码的一次性密码（OTP） |
| `project` | string | 否 | 项目的唯一标识符。可选，有助于缩小验证范围 |
| `projectFlow` | string | 否 | 项目流程的唯一标识符。可选，有助于缩小验证范围 |
| `phoneGateway` | string | 否 | 使用的投递方式：`sms`、`whatsapp` 或 `none` |

### 说明

- **Onboarding 流程**：此端点专为处于 App Registration 过程中的用户设计，其中手机验证是 onboarding 旅程的一部分。
- **OTP 过期**：OTP 有有限的有效期（通常为 10 分钟），会在预定时间后过期。已过期的 OTP 无法验证。
- **状态更新**：验证成功会自动将手机验证状态更新为 `"validated"`，并可能触发额外的 onboarding 步骤。
- **Webhook 事件**：验证事件会触发 webhook 通知，用于跟踪与集成。
- **人脸活体**：部分项目流程可能在手机验证后建议进行人脸活体验证，作为 onboarding 过程的一部分。
- **App Registration 关联**：通过此端点验证时，手机验证会自动关联到用户的 App Registration 记录。
- **手机号码格式**：处理过程中会自动移除手机号码中的空格。
- **国家代码格式**：国家代码必须为 `+XXX` 格式，其中 X 为数字（最多 1–3 位）。
