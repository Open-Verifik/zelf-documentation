# 哥伦比亚 — 按姓名查询公民（SCCRC）

使用 **姓名**、**性别** 与 **出生日期** 搜索 **Registraduría Nacional del Estado Civil** 出生民事登记簿（**SCCRC**）。与[按证件查询哥伦比亚公民](/verifik-zh/identity-validation/colombia/colombian-citizen)不同，此端点为**反向查询**，可能返回**多条匹配**。

适用于已知个人身份属性但不知 NUIP/CC，或需要在证件核验前确认可能的登记命中时。

## 此 API 返回的内容

- **`matches`** — 民事登记命中数组（零条或多条）
- **`documentNumber`**、**`documentType`** — 记录中存在时的 NUIP/CC
- **`firstName`**、**`lastName`**、**`fullName`**、**`arrayName`** — 姓名组成部分
- **`sexo`**、**`serial`** — 性别与民事登记序列号
- **`oficina`** / **`expeditionPlace`**、**`fecha`** / **`dateOfBirth`** — 在有 Detalle 补全数据时可用
- **`recordType`** — `REGISTRO CIVIL DE NACIMIENTO`
- **已签名**的 Verifik 响应包装

## API 参考

### 端点

```
GET https://api.verifik.co/v2/co/cedula/by-name
```

需要**按姓名查找出生登记候选**时使用此端点。同一集成也支持带 JSON 正文的 **`POST`**。**`GET`** 使用如下所示的**查询参数**。

### 请求头（Headers）

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### 参数（Parameters）

| name | type | required | description | Examples |
| --- | --- | --- | --- | --- |
| `primerNombre` | string | yes | 第一名（名） | `MARIA` |
| `primerApellido` | string | yes | 第一姓 | `LOPEZ` |
| `sexo` | string | yes | 登记性别。允许：`MASCULINO`、`FEMENINO`（也可用 `M` / `F`） | `FEMENINO` |
| `fecha` | string | yes | 出生日期，格式 **`DD/MM/YYYY`** | `15/03/1990` |
| `segundoNombre` | string | no | 第二名 | `ELENA` |
| `segundoApellido` | string | no | 第二姓 | `GARCIA` |

## 功能

- 针对 Registraduría **SCCRC** 出生登记的**反向查询**
- 响应始终为 **`{ matches: [...] }`** 形态（请审查每一条命中）
- 可选第二名/第二姓可提高精确度
- **GET** 与 **POST** 共用同一处理程序

## 使用场景

- 根据已知姓名 + 出生日期恢复可能的 **NUIP/CC** 候选
- 仅有传记数据时对申请人进行预筛
- 对照民事登记命中交叉核验姓名拼写

### 说明（Notes）

- 请始终检查 **`matches`**；姓名查询可能返回一人以上。
- **`fecha`** 必须为 **`DD/MM/YYYY`**（出生日期）。
- **沙箱：** 姓名查询映射到证件号 **`10000001`–`10000010`** 的固定档案。示例默认值：`MARIA` / `LOPEZ` / `FEMENINO` / `15/03/1990`。
- 来源暂时不可用时可能表现为 **409**（`Endpoint_out_of_service`）。
