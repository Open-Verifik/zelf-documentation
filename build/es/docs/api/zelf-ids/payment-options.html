Payment Options

Return unique payment addresses, per-network quotes, and a JWT (signedDataPrice) to buy Premium or Unlimited for a Zelf ID that is already leased. Prices come only from the domain license plan pricing (planPricing), and the license also decides which terms are offered. Pass plan=premium or plan=unlimited for names of 6–27 characters. Names of 1–5 characters can only buy unlimited, and a premium quote for them is refused. New leases no longer create .hold reservations; an older unpaid .hold still converts when it is paid. Pass coupon to apply a percent-off coupon. A rejected code comes back on this quote with coupon.reason, and the license price stays the amount due. Do not call /api/my-tags/payment-options for v4 names.

For a 6+ character .zelf name the license currently offers these terms:

durationPremiumUnlimited
"1"$29.00$99.00
"2"$43.49$148.99
"3"$56.99$192.99
"lifetime"$144.99$494.99

These are a snapshot. Always show the amountDue of a fresh quote.

For what Free, Premium and Unlimited include, upgrade credit, renewal and lapse, see Plans: Free, Premium and Unlimited.

Endpoint​

GET https://v4.zelf.world/api/zelf-ids/payment-options

Authentication​

Requires a JWT token obtained from POST /api/sessions.

Parameters​

ParameterTypeRequiredDescription
tagNamestringYesBare name of the leased Zelf ID (e.g., "myname")
domainstringYesDomain TLD (e.g., "zelf")
durationstringYesA term the license offers for this plan and name length. Today "1", "2", "3" (years) or "lifetime". "999" is accepted as "lifetime". Any other term, such as "4" or "5", returns 409 PLAN_DURATION_NOT_OFFERED_BY_LICENSE.
planstringNo"premium" or "unlimited". Send it for 6–27 character names. Names of 1–5 characters are always unlimited.
couponstringNoCoupon code. Case-insensitive. See Coupons.

  • 200 OK
  • 404 Not Found
  • 409 Conflict
  • 401 Unauthorized

message and code are both TAG_NOT_FOUND. GET /api/zelf-ids/my-plan uses this same body. The name is available or was never leased. Lease it first.

{
  "validationError": "\"tagName\" is required"
}

A term or plan the license does not offer, or a license with no plan pricing, is checked before the quote is built. It returns 409 with the code in validationError:

{ "validationError": "PLAN_DURATION_NOT_OFFERED_BY_LICENSE" }
{ "validationError": "PLAN_NOT_OFFERED_FOR_NAME" }
{ "validationError": "LICENSE_PRICE_REQUIRED" }

A downgrade while the paid term is open returns 409 with the code in both message and code:

{ "message": "PLAN_DOWNGRADE_NOT_ALLOWED", "code": "PLAN_DOWNGRADE_NOT_ALLOWED" }
{
  "error": "Protected resource, use Authorization header to get access"
}

Response Fields​

FieldTypeDescription
tagNamestringFull name (name.domain)
tagPayNamestringUnique pay-record name (name.domainpay)
planstringPlan this payment applies: premium or unlimited
allowedPlansstring[]Plans the license offers for this name length
durationnumber or stringTerm in years, or "lifetime"
expiresAtstringCurrent expiration stored on the name
newExpiresAtstringExpiration this purchase would stamp
listPricenumberLicense price in USD for this plan and term, before upgrade credit and coupon
upgradeCreditnumberUSD credit from an open Premium term when upgrading to Unlimited. 0 otherwise. See Upgrading
amountDuenumberUSD to pay after upgrade credit and coupon. Show this to the user
freeCheckoutbooleantrue when a coupon or whitelist brings the total to $0. Confirm with network FREE
paymentAddressobjectUnique BTC / SOL (and ETH when not moved onto a contract quote)
pricesobjectPer-network amountToSend for amountDue. price is that USD amount
signedDataPricestringJWT to send as token on Payment Confirmation
ttlnumberUnix time when the quote expires (2 hours)

Examples​

  • cURL
  • Node.js
  • Python
  • PHP
  • Rust
curl -X GET "https://v4.zelf.world/api/zelf-ids/payment-options?tagName=myname&domain=zelf&duration=1" \
  -H "Origin: https://yourdomain.com" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
const axios = require('axios');

const response = await axios.get('https://v4.zelf.world/api/zelf-ids/payment-options', {
  params: { tagName: 'myname', domain: 'zelf', duration: '1' },
  headers: { Authorization: `Bearer ${token}`, Origin: 'https://yourdomain.com' }
});

console.log(response.data.data.signedDataPrice);
console.log(response.data.data.paymentAddress.solanaAddress);
import requests

response = requests.get(
    "https://v4.zelf.world/api/zelf-ids/payment-options",
    params={"tagName": "myname", "domain": "zelf", "duration": "1"},
    headers={"Authorization": f"Bearer {token}", "Origin": "https://yourdomain.com"},
)
quote = response.json()["data"]
print(quote["signedDataPrice"])
<?php
$ch = curl_init('https://v4.zelf.world/api/zelf-ids/payment-options?tagName=myname&domain=zelf&duration=1');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . $token,
        'Origin: https://yourdomain.com',
    ],
]);
$result = json_decode(curl_exec($ch), true);
echo $result['data']['signedDataPrice'];
use reqwest;
use serde_json::Value;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = reqwest::Client::new();
    let response = client
        .get("https://v4.zelf.world/api/zelf-ids/payment-options")
        .query(&[("tagName", "myname"), ("domain", "zelf"), ("duration", "1")])
        .header("Origin", "https://yourdomain.com")
        .header("Authorization", format!("Bearer {}", token))
        .send()
        .await?;
    let body: Value = response.json().await?;
    println!("{}", body["data"]["signedDataPrice"]);
    Ok(())
}
