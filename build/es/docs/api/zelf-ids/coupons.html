Coupons

A coupon takes a percent off a paid Zelf ID plan. It applies to premium, unlimited, or both. The list price is the license plan price for that name and duration (tags.payment.pricingTable, via domainConfig.getPrice). See The License Object. A coupon does not add another price list.

The name's plan also sets its Zelf Keys password and 2FA limits. For what each plan includes, limits, extra slots, renewal and lapse, see Plans: Free, Premium and Unlimited.

Quote with Payment Options. A 100% coupon grants the plan on the same free-checkout path as a $0 quote. A partial coupon charges the discounted amount on the normal Stripe or crypto checkout.

Coupon​

FieldTypeDescription
idstringServer id.
codestringUnique. Compared case-insensitively, stored uppercase. save100 and SAVE100 are one coupon.
percentOffnumberInteger from 1 to 100.
plansstring[]premium, unlimited, or both.
durationsstring[]Optional. 1y, 2y, 3y, lifetime. Omit to allow every quote duration ("1" … "5" and "lifetime").

perZelfIdLimitnumberSuccessful redemptions per Zelf ID. Default 1.
expiresAtstringOptional ISO-8601 time. Omit for no time limit.
activebooleanfalse after deactivate. New coupons start true.
createdBystringSuper-admin who created it. Set by the server.
redemptionsarray{ zelfId, plan, duration, redeemedAt } for each grant.
durations entryQuote duration
1y"1"
2y"2"
3y"3"
lifetime"lifetime"

The redemption log stores that same duration token (1y, 2y, 3y, lifetime, and 4y or 5y when the coupon leaves duration open).

Quote​

GET https://v4.zelf.world/api/zelf-ids/payment-options

Authentication​

Requires a JWT from POST /api/sessions.

Parameters​

Same query as Payment Options, plus:

ParameterTypeRequiredDescription
couponstringNoCoupon code. Case-insensitive.

The API checks, in this order: the code exists, active is true, expiresAt is still in the future, redemptions are under maxRedemptions, plan is allowed, duration is allowed, and this Zelf ID is under perZelfIdLimit.

A failed check still returns the quote. amountDue stays the license price, and coupon.reason says why. A failed check does not write a redemption.

With no upgrade credit, amountDue = listPrice × (100 − percentOff) / 100. A Premium-to-Unlimited upgrade subtracts upgradeCredit before the coupon. See Upgrade credit. The figures below use the example license row for a 6–15 character name, one year, $24. Each TLD sets its own table.

Checkout​

100% (amountDue is 0)​

Confirm the signed quote with Payment Confirmation. Send tagName, domain, and token. Omit network.

The API grants the plan on the free-checkout path. It does not call Stripe, RevenueCat, or crypto, and it does not issue a pay address. The lease payment method is coupon, with couponId set to this coupon’s id. The redemption is inserted in the same transaction as the grant, so concurrent confirms cannot pass maxRedemptions.

The grant uses the same purchase rules as a paid checkout:

  • Upgrade order is free → premium → unlimited.
  • A lower plan is rejected while a paid plan term is still active (DOWNGRADE_NOT_ALLOWED). A renewal or an upgrade extends or replaces only that plan term.
  • Names of 1–5 characters are unlimited only (PLAN_NOT_ALLOWED_FOR_NAME for premium).
  • Names of 6–27 characters can be premium or unlimited.
  • Duration must be one the quote accepts and one this coupon allows.

A rejected grant does not write a redemption. Create and redeem each write an audit log entry.

Partial (percentOff under 100)​

Stripe and crypto charge amountDue. Crypto quotes in prices and the signedDataPrice JWT use that discounted USD amount. Confirm crypto with payment confirmation and network, as usual. The redemption is written when that checkout grants the plan.

Plan term and the name lease​

A Free name that buys premium or unlimited for 1y or longer, paid by Stripe, crypto, coupon, or whitelist, keeps its 100-year Free lease. The paid plan ends at planExpiresAt. The name ends at leaseExpiresAt. When the paid term ends, plan is free and planExpiresAt stays on that past end date. Free limits apply again. The name does not expire. A renewal or an upgrade changes only the plan term. An Unlimited lifetime plan has no planExpiresAt. Names of 1–5 characters still only buy unlimited.

Upgrading a plan​

GET https://v4.zelf.world/api/zelf-ids/my-plan?zelfName=myname.zelf

The caller must be the verified owner. On the session, verifiedTagName must equal the normalized zelfName, and the request must fall inside verifiedUntil. A missing session is 401. A session that fails that match is 403.

  "zelfName": "myname.zelf",
  "plan": "premium",
  "duration": "1y",
  "planExpiresAt": "2027-10-24T18:00:00.000Z",

plan is the effective plan right now: free, premium, or unlimited. After a paid term lapses, plan is free and planExpiresAt is that past end date. leaseExpiresAt is the name lease. expiresAt is that same name-lease expiry, kept for older clients. paymentMethod is free, stripe, stripe_subscription, crypto, coupon, revenuecat, or whitelist. A $0 license whitelist checkout stores paymentMethod whitelist. nextPlans lists what this name can still buy. upgrade.url is present only when the action has a link.

Zelf ID Stripe checkout is a one-off payment today. stripe_portal applies only when the lease stores paymentMethod stripe_subscription. Upgrade links use https://zelf.world unless LANDING_URL overrides that host.

Upgrade credit​

When a name on an active paid premium term upgrades to unlimited, unused Premium time is a discount on the Unlimited price.

upgradeCredit is the amount actually paid for the current Premium term × (remaining seconds / total term seconds), rounded down to the cent, and capped at the Unlimited price. The server locks that credit and the prices inside the signed quote (signedDataPrice) for the quote's validity window. Confirm honors those locked figures and does not recompute them.

A term granted by a 100% coupon or a whitelist ($0 paid) gets $0 credit. A partial coupon credits the amount that was actually paid. A lifetime term and a lapsed term get no credit.

The new Unlimited term starts on the upgrade date. Unused Premium time is not added onto that term.

GET /api/zelf-ids/payment-options returns listPrice, upgradeCredit, and amountDue. The coupon applies after the credit:

amountDue = (listPrice − upgradeCredit) × (100 − percentOff) / 100

Half of a $24 Premium term is $12.00 of credit. If Unlimited lists at $48, amountDue is $36 before a coupon.

An expired quote is rejected. The client requests a new quote, which recomputes the credit and the prices. Crypto prices can change between quotes. A Stripe Checkout session expires when the quote expires. A quote with under 30 minutes left returns 409 QUOTE_EXPIRING. If the Premium term behind the credit is no longer the current term, confirm returns 409 UPGRADE_TERM_CHANGED. An Unlimited lifetime name returns 409 ALREADY_LIFETIME from payment-options.

A final amount of $0 uses the free-grant path. Identity is required, and no payment gateway is called. When amountDue is above $0 and below the Stripe minimum, Stripe returns STRIPE_AMOUNT_BELOW_MINIMUM. Crypto checkout still works.

Admin​

Create, list, and deactivate require a super-admin session JWT. Any other session receives 403.

POST https://v4.zelf.world/api/zelf-ids/coupons
GET  https://v4.zelf.world/api/zelf-ids/coupons
POST https://v4.zelf.world/api/zelf-ids/coupons/:id/deactivate

Deactivate sets active to false and keeps the redemption log. The code stays reserved.

Error codes​

Quote rejections are HTTP 200. coupon.reason is one of:

reasonMeaning
NOT_FOUNDNo coupon for that code.
INACTIVEactive is false.
EXPIREDexpiresAt has passed.
MAX_REDEMPTIONSSuccessful redemptions have reached maxRedemptions.
PLAN_NOT_ALLOWEDplan is not on this coupon.
DURATION_NOT_ALLOWEDduration is not on this coupon.
ZELF_ID_LIMITThis Zelf ID has reached perZelfIdLimit.
HTTPcodeWhen
401—Missing session JWT. Body is { "error": "Protected resource, use Authorization header to get access" }.
403SUPER_ADMIN_REQUIREDAdmin route, caller is not a super-admin.
409COUPON_CODE_TAKENCreate, code already exists.
409COUPON_INVALIDGrant-time recheck failed. code is the quote reason above.
409DOWNGRADE_NOT_ALLOWEDPaid lease is active and the requested plan is lower.
409PLAN_NOT_ALLOWED_FOR_NAMEPremium on a name of 5 characters or fewer.
409—Body validation. validationError text, same shape as other Zelf ID routes.

<?php
$ch = curl_init('https://v4.zelf.world/api/zelf-ids/payment-options?tagName=myname&domain=zelf&duration=1&plan=premium&coupon=SAVE25');

use reqwest;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = reqwest::Client::new();
    let response = client
        .get("https://v4.zelf.world/api/zelf-ids/payment-options")
        .query(&[
            ("tagName", "myname"),
            ("domain", "zelf"),
            ("duration", "1"),
            ("plan", "premium"),
            ("coupon", "SAVE25"),
        ])
        .header("Origin", "https://yourdomain.com")
        .header("Authorization", format!("Bearer {}", token))
        .send()
        .await?;
    let body: Value = response.json().await?;
    println!("{}", body["data"]["amountDue"]);
    Ok(())
}
