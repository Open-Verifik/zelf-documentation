### Endpoint

```
POST https://api.verifik.co/v2/phone-validations/app-registration
```

Phone Validation は、アプリ登録プロセス中に電話番号を処理・検証できる、Verifik システム内のインスタンスです。このプロセスによりユーザーの電話番号の真正性が確保され、SMS または WhatsApp の配信方法による安全な確認が可能になります。

:::warning
`App Registration Phone Validations` を作成するときに使用する JWT Token は、`App Registration` の作成時に提供されます。[App Registration](https://docs.verifik.co/resources/app-registrations/create-an-app-registration) の作成時に返されるトークンを使用して、このリクエストを認証する必要があります。
:::

### Headers

| Name | Value |
| --- | --- |
| Content-Type | `application/json` |
| Authorization | `Bearer <token>` |

### Params

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `project` | string | Yes | この電話番号認証が使用されるプロジェクトの一意の識別子 |
| `validationMethod` | string | Yes | 検証方法。`verificationCode` である必要があります |
| `phone` | string | Yes | 検証対象の電話番号。処理中にスペースは自動的に除去されます |
| `countryCode` | string | Yes | 電話番号の国コード。形式は `+XXX`（例: パナマは `+507`、米国は `+1`）。`+` の後に 1〜3 桁の数字という形式に一致する必要があります |
| `type` | string | Yes | 検証の種類。次のいずれかである必要があります: `validation`、`login`、`onboarding`、または `oneTimeLink` |
| `expiresAt` | string | No | 検証コードの任意の有効期限。指定しない場合、デフォルトの有効期限が設定されます。形式: ISO 8601（例: `2024-12-31T23:59:59.000Z`） |
| `redirectUrl` | string | No | 検証後のリダイレクト用の任意の URL |
| `webhookUrl` | string | No | 検証通知用の任意の Webhook URL |
| `identityUrl` | string | No | 任意のアイデンティティ検証 URL |
| `requires2FA` | boolean | No | 二要素認証が必要かどうかを示す任意のフラグ。デフォルトは `false` |
| `ipAddress` | string | No | ユーザーの任意の IP アドレス |

#### Validation Method Values

| Value | Description |
| --- | --- |
| `verificationCode` | 確認用のワンタイムパスワード（OTP）を電話番号に送信します |

#### Type Values

| Value | Description |
| --- | --- |
| `onboarding` | ユーザー登録時の電話番号確認（App Registration 向けに推奨） |
| `validation` | 一般的な電話番号検証 |
| `login` | ユーザーログイン時の電話番号確認 |
| `oneTimeLink` | ワンタイムリンク検証 |

### Notes

- **国コードの形式**: `countryCode` は `+XXX` 形式である必要があります（X は数字、最大 1〜3 桁）。例: `+1`、`+507`、`+52`。
- **電話番号**: 電話番号内のスペースは処理中に自動的に除去されます。
- **OTP のセキュリティ**: OTP はセキュリティのため、保存前に bcrypt で暗号化されます。
- **デフォルトのゲートウェイ**: 電話番号認証は、プロジェクトフローの設定に基づき、デフォルトで WhatsApp 配信になります。
- **自動リンク**: app-registration エンドポイント経由で作成すると、電話番号認証はユーザーの App Registration レコードに自動的にリンクされます。
- **クレジット課金**: このエンドポイントは SmartEnroll プランから自動的にクレジットを課金します。
- **App Registration が必要**: このエンドポイントにはアクティブな App Registration セッションが必要です。App Registration 作成時に返されるトークンを使用する必要があります。
