### Endpoint

```
GET https://api.verifik.co/v2/phone-validations
```

このサービスは、任意のフィルタリングとページネーションで、すべての電話番号認証の一覧を取得します。プロジェクト、ステータス、種類などのパラメータでフィルタし、特定の電話番号認証を見つけられます。

#### Headers

#### `Content-Type`

**Type:** String  
**Required:** Required  
**Value:** `application/json`

#### `Authorization`

**Type:** String  
**Required:** Required  
**Value:** `Bearer {YOUR_ACCESS_TOKEN}`

#### Query Parameters

#### `page`

**Type:** Number  
**Required:** No

ページネーション用のページ番号（デフォルト: 1）。

#### `limit`

**Type:** Number  
**Required:** No

ページあたりのレコード数（デフォルト: 10、最大: 100）。

#### `project`

**Type:** String  
**Required:** No

プロジェクト ID でフィルタします。

#### `status`

**Type:** String  
**Required:** No

ステータスでフィルタ: `new`、`sent`、`validated`、`failed`。

#### `type`

**Type:** String  
**Required:** No

種類でフィルタ: `validation`、`login`、`onboarding`。

#### `countryCode`

**Type:** String  
**Required:** No

国コードでフィルタします。

#### `phone`

**Type:** String  
**Required:** No

電話番号でフィルタします。

#### `populates[]`

**Type:** String  
**Required:** No

含める関連データの任意の配列。利用可能なオプション: `client`、`project`、`projectFlow`。

## Features

- **完全な一覧**: アカウント内のすべての電話番号認証を取得
- **ページネーション**: page と limit によるページネーションに対応
- **高度なフィルタリング**: プロジェクト、ステータス、種類、国コード、電話番号でフィルタ
- **データのポピュレート**: クライアントやプロジェクトなどの関連情報を含める
- **複数の状態**: ステータス（new、sent、validated、failed）でフィルタ
- **国コード**: 国際国コードによる具体的なフィルタリング
- **複数言語**: JavaScript、Python、PHP、Swift に対応
- **詳細情報**: 試行回数、上限、検証タイムスタンプを含む
