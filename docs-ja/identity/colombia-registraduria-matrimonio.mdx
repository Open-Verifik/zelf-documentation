# コロンビア — 婚姻民事登記（SCCRC）

**Registraduría Nacional del Estado Civil**（**SCCRC**）の **婚姻民事登記簿**（*registro civil de matrimonio*）を照会します。

検索モードは **いずれか 1 つ** を指定してください。

1. **`documentNumber` + `sexo`** — 書類検索（単一レコード）
2. **`primerNombre` + `primerApellido` + `sexo` + `fecha`** — 氏名検索（**`matches`** を返す場合あり）
3. **`serial`** — シリアル検索（単一レコード）

## この API が返す内容

- 単一レコード **または** **`matches`** 配列（氏名モード）
- **`documentNumber`**, **`documentType`**, 氏名, **`sexo`**, **`serial`**
- 利用可能な場合 **`oficina`** / **`expeditionPlace`**, **`fecha`**
- **`recordType`** — `REGISTRO CIVIL DE MATRIMONIO`
- **署名付き** Verifik レスポンスラッパー

## API リファレンス

### エンドポイント

```
GET https://api.verifik.co/v2/co/registraduria/matrimonio
```

**婚姻登記** の検索にこのエンドポイントを使用します。同じ連携は JSON ボディの **`POST`** でも利用できます。**`GET`** は下記の **クエリパラメーター** を使用します。

### ヘッダー（Headers）

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### パラメーター（Parameters）

| name | type | required | description | Examples |
| --- | --- | --- | --- | --- |
| `documentNumber` | string | conditional | NUIP/CC; **`sexo`** が必要 | `10000001` |
| `sexo` | string | conditional | 書類または氏名検索で必須（`MASCULINO` / `FEMENINO`） | `MASCULINO` |
| `serial` | string | conditional | 婚姻登記シリアル | `0042012345` |
| `primerNombre` | string | conditional | 第一名（氏名モード） | `JUAN` |
| `primerApellido` | string | conditional | 第一姓（氏名モード） | `PEREZ` |
| `fecha` | string | conditional | 婚姻日 **`DD/MM/YYYY`**（氏名モード） | `20/06/2015` |
| `segundoNombre` | string | no | 第二名 | `CARLOS` |
| `segundoApellido` | string | no | 第二姓 | `GOMEZ` |

## 機能

- 3 つの検索モード: **書類**、**氏名**、または **シリアル**
- 氏名モードは **`matches`** を返す場合あり; 書類/シリアルは単一オブジェクトを返す
- **GET** と **POST** は同一ハンドラーを共有

## ユースケース

- KYC / コンプライアンス向けに **婚姻登記** ヒットを確認
- 既知書類に紐づく婚姻シリアルを解決
- 伝記データのみの氏名ベース・スクリーニング

### Notes

- 検索モードは **正確に 1 つ** のみ指定してください（シリアルを書類/氏名フィールドと混在させないでください）。
- **サンドボックス:** 文書番号 **`10000001`–`10000010`**; 氏名モードは [氏名検索](/verifik-ja/identity-validation/colombia/colombian-citizen-by-name) と同じサンドボックスプロファイルに従います。
- ソースの一時的な可用性の問題は **409**（`Endpoint_out_of_service`）として現れることがあります。
- 関連: [書類による市民検索](/identity-validation/colombia/colombian-citizen)、[氏名による市民検索](/verifik-ja/identity-validation/colombia/colombian-citizen-by-name)、[シリアルによる民事登記検索](/verifik-ja/identity/colombia-registraduria-serial)、[Registraduría 証明書](/verifik-ja/identity/colombia-registraduria-certificate)。
