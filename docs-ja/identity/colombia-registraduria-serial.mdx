# コロンビア — シリアルによる民事登記検索（SCCRC）

登記文書に印字された **シリアル** を使い、**Registraduría Nacional del Estado Civil**（**SCCRC**）の **出生民事登記** 記録（*registro civil de nacimiento*）を特定します。

民事登記シリアルが既にある場合、[書類による市民検索](/identity-validation/colombia/colombian-citizen) および [氏名による検索](/verifik-ja/identity-validation/colombia/colombian-citizen-by-name) を補完します。

## この API が返す内容

- **`documentNumber`**, **`documentType`** — ある場合の NUIP/CC
- **`firstName`**, **`lastName`**, **`fullName`**, **`arrayName`**
- **`sexo`**, **`serial`**
- 利用可能な場合 **`oficina`** / **`expeditionPlace`**, **`fecha`** / **`dateOfBirth`**
- **`recordType`** — `REGISTRO CIVIL DE NACIMIENTO`
- **署名付き** Verifik レスポンスラッパー

## API リファレンス

### エンドポイント

```
GET https://api.verifik.co/v2/co/registraduria/serial
```

**民事登記シリアル** があり、紐づく本人確認フィールドが必要なときにこのエンドポイントを使用します。同じ連携は JSON ボディの **`POST`** でも利用できます。**`GET`** は下記の **クエリパラメーター** を使用します。

### ヘッダー（Headers）

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### パラメーター（Parameters）

| name | type | required | description | Examples |
| --- | --- | --- | --- | --- |
| `serial` | string | yes | 民事登記シリアル（最大 **10** 桁、先頭ゼロ可） | `0031058170` |

## 機能

- *registro civil de nacimiento* に印字された **シリアル** で検索
- 単一レコード応答（`matches` 配列ではない）
- **GET** と **POST** は同一ハンドラーを共有

## ユースケース

- 物理的な **registro civil** のデータをデジタル化または検証
- 既知の民事登記シリアルから NUIP/CC を解決
- 文書番号ではなくシリアルを保存する監査証跡

### Notes

- **`serial`** は数字のみ（先頭ゼロのパディングは受理されます）。
- **サンドボックスの例示シリアル:** `0031058170`（サンドボックス文書番号 **`10000001`–`10000010`** にマッピング）。
- ソースの一時的な可用性の問題は **409**（`Endpoint_out_of_service`）として現れることがあります。
