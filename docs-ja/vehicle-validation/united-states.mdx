# 🇺🇸 アメリカ合衆国 — 車両情報

:::info 一時的に利用不可
米国車両の **ナンバープレートと州** による照会（`GET /v2/usa/vehicle`）は一時的に無効化されており、新規連携では利用できません。

代わりに **VIN による車両照会** を利用してください:

- **[アメリカ合衆国 — 車両（VIN）](/verifik-ja/vehicle-validation/united-states/vehicle-by-vin)** — `GET /v2/usa/vehicle-by-vin`
:::

### Endpoint

```
GET https://api.verifik.co/v2/usa/vehicle
```

このルートは以前、クエリパラメータ `plate` と `state` を受け付けていました。プレート照会がオフラインの間は VIN エンドポイントを優先してください。
