# Colômbia — Consulta de registro civil por serial (SCCRC)

Localize um registro civil de **nascimento** (*registro civil de nacimiento*) da **Registraduría Nacional del Estado Civil** (**SCCRC**) usando o **serial** impresso no documento do registro.

Isso complementa [cidadão por documento](/identity-validation/colombia/colombian-citizen) e [consulta por nome](/identity-validation/colombia/colombian-citizen-by-name) quando você já possui o serial do registro civil.

## O que esta API retorna

- **`documentNumber`**, **`documentType`** — NUIP/CC quando presentes
- **`firstName`**, **`lastName`**, **`fullName`**, **`arrayName`**
- **`sexo`**, **`serial`**
- **`oficina`** / **`expeditionPlace`**, **`fecha`** / **`dateOfBirth`** quando disponíveis
- **`recordType`** — `REGISTRO CIVIL DE NACIMIENTO`
- Um wrapper de resposta Verifik **assinado**

## Referência da API

### Endpoint

```
GET https://api.verifik.co/v2/co/registraduria/serial
```

Use este endpoint quando você tem o **serial do registro civil** e precisa dos campos de identidade vinculados. A mesma integração está disponível como **`POST`** com corpo JSON. **`GET`** usa **parâmetros de consulta** conforme mostrado abaixo.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| name | type | required | description | Examples |
| --- | --- | --- | --- | --- |
| `serial` | string | yes | Serial do registro civil (até **10** dígitos; zeros à esquerda permitidos) | `0031058170` |

## Recursos

- Consulta pelo **serial** impresso no *registro civil de nacimiento*
- Resposta de registro único (não um array `matches`)
- **GET** e **POST** compartilham o mesmo handler

## Casos de uso

- Digitalizar ou validar dados de um **registro civil** físico
- Resolver NUIP/CC a partir de um serial de registro civil conhecido
- Trilhas de auditoria que armazenam serials em vez de números de documento

### Notes

- **`serial`** contém apenas dígitos (preenchimento com zeros à esquerda é aceito).
- **Serial de exemplo no sandbox:** `0031058170` (mapeia para números de documento sandbox na faixa **`10000001`–`10000010`**).
- Problemas temporários de disponibilidade da fonte podem aparecer como **409** (`Endpoint_out_of_service`).
