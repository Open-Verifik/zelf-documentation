# Colômbia — Registro civil de casamento (SCCRC)

Consulte o **registro civil de casamento** (*registro civil de matrimonio*) da **Registraduría Nacional del Estado Civil** (**SCCRC**).

Forneça **um** modo de busca:

1. **`documentNumber` + `sexo`** — busca por documento (registro único)
2. **`primerNombre` + `primerApellido` + `sexo` + `fecha`** — busca por nome (pode retornar **`matches`**)
3. **`serial`** — busca por serial (registro único)

## O que esta API retorna

- Registro único **ou** um array **`matches`** (modo nome)
- **`documentNumber`**, **`documentType`**, nomes, **`sexo`**, **`serial`**
- **`oficina`** / **`expeditionPlace`**, **`fecha`** quando disponíveis
- **`recordType`** — `REGISTRO CIVIL DE MATRIMONIO`
- Um wrapper de resposta Verifik **assinado**

## Referência da API

### Endpoint

```
GET https://api.verifik.co/v2/co/registraduria/matrimonio
```

Use este endpoint para consultas do **registro de casamento**. A mesma integração está disponível como **`POST`** com corpo JSON. **`GET`** usa **parâmetros de consulta** conforme mostrado abaixo.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| name | type | required | description | Examples |
| --- | --- | --- | --- | --- |
| `documentNumber` | string | conditional | NUIP/CC; exige **`sexo`** | `10000001` |
| `sexo` | string | conditional | Obrigatório para busca por documento ou nome (`MASCULINO` / `FEMENINO`) | `MASCULINO` |
| `serial` | string | conditional | Serial do registro de casamento | `0042012345` |
| `primerNombre` | string | conditional | Primeiro nome (modo nome) | `JUAN` |
| `primerApellido` | string | conditional | Primeiro sobrenome (modo nome) | `PEREZ` |
| `fecha` | string | conditional | Data do casamento **`DD/MM/YYYY`** (modo nome) | `20/06/2015` |
| `segundoNombre` | string | no | Segundo nome | `CARLOS` |
| `segundoApellido` | string | no | Segundo sobrenome | `GOMEZ` |

## Recursos

- Três modos de busca: **documento**, **nome** ou **serial**
- O modo nome pode retornar **`matches`**; documento/serial retornam um único objeto
- **GET** e **POST** compartilham o mesmo handler

## Casos de uso

- Confirmar um resultado do **registro de casamento** para KYC / conformidade
- Resolver serials de casamento vinculados a um documento conhecido
- Triagem por nome quando apenas dados biográficos estão disponíveis

### Notes

- Forneça **exatamente um** modo de busca (não misture serial com campos de documento/nome).
- **Sandbox:** números de documento **`10000001`–`10000010`**; o modo nome segue os mesmos perfis sandbox que [por nome](/identity-validation/colombia/colombian-citizen-by-name).
- Problemas temporários de disponibilidade da fonte podem aparecer como **409** (`Endpoint_out_of_service`).
