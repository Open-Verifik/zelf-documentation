# 🇺🇸 Estados Unidos — Informações do veículo (placa)

:::info Temporariamente indisponível
A consulta de veículos dos EUA por **placa e estado** (`GET /v2/usa/vehicle`) está temporariamente desabilitada e não está disponível para novas integrações.

Use **Veículo por VIN** em vez disso:

- **[Estados Unidos — Veículo por VIN](/verifik-pt/vehicle-validation/united-states/vehicle-by-vin)** — `GET /v2/usa/vehicle-by-vin`
:::

### Endpoint

```
GET https://api.verifik.co/v2/usa/vehicle
```

Esta rota aceitava os parâmetros de consulta `plate` e `state`. Prefira o endpoint por VIN enquanto a consulta por placa permanecer offline.
