### Endpoint

```
GET https://api.verifik.co/v2/phone-validations
```

Este serviço recupera uma lista de todas as validações de telefone com filtragem e paginação opcionais. Você pode filtrar por projeto, status, tipo e outros parâmetros para encontrar validações de telefone específicas.

#### Headers

#### `Content-Type`

**Type:** String  
**Required:** Required  
**Value:** `application/json`

#### `Authorization`

**Type:** String  
**Required:** Required  
**Value:** `Bearer {YOUR_ACCESS_TOKEN}`

#### Query Parameters

#### `page`

**Type:** Number  
**Required:** No

Número da página para paginação (padrão: 1).

#### `limit`

**Type:** Number  
**Required:** No

Número de registros por página (padrão: 10, máx.: 100).

#### `project`

**Type:** String  
**Required:** No

Filtrar por ID do projeto.

#### `status`

**Type:** String  
**Required:** No

Filtrar por status: `new`, `sent`, `validated`, `failed`.

#### `type`

**Type:** String  
**Required:** No

Filtrar por tipo: `validation`, `login`, `onboarding`.

#### `countryCode`

**Type:** String  
**Required:** No

Filtrar por código do país.

#### `phone`

**Type:** String  
**Required:** No

Filtrar por número de telefone.

#### `populates[]`

**Type:** String  
**Required:** No

Array opcional de dados relacionados a incluir. Opções disponíveis: `client`, `project`, `projectFlow`.

## Recursos

- **Listagem completa**: Recupera todas as validações de telefone da sua conta
- **Paginação**: Suporte a paginação com controle de página e limite
- **Filtragem avançada**: Filtre por projeto, status, tipo, código do país e número de telefone
- **População de dados**: Inclua informações relacionadas, como dados de cliente e projeto
- **Vários estados**: Filtre por status (new, sent, validated, failed)
- **Códigos de país**: Filtragem específica por código internacional do país
- **Vários idiomas**: Suporte a JavaScript, Python, PHP e Swift
- **Informações detalhadas**: Inclui tentativas, limites e timestamps de validação
