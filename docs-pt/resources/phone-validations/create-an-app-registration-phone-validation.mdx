### Endpoint

```
POST https://api.verifik.co/v2/phone-validations/app-registration
```

Uma Validação de Telefone é uma instância no sistema da Verifik que permite processar e validar números de telefone durante o processo de app registration. Esse processo garante a autenticidade dos números de telefone dos usuários e oferece verificação segura por meio de métodos de entrega SMS ou WhatsApp.

:::warning
O token JWT que você deve usar ao criar `App Registration Phone Validations` é fornecido na criação do `App Registration`. Você deve usar o token retornado ao criar um [App Registration](https://docs.verifik.co/resources/app-registrations/create-an-app-registration) para autenticar esta requisição.
:::

### Headers

| Name | Value |
| --- | --- |
| Content-Type | `application/json` |
| Authorization | `Bearer <token>` |

### Params

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `project` | string | Yes | O identificador único do projeto em que esta validação de telefone será usada |
| `validationMethod` | string | Yes | O método de validação. Deve ser `verificationCode` |
| `phone` | string | Yes | O número de telefone que será validado. Espaços serão removidos automaticamente durante o processamento |
| `countryCode` | string | Yes | O código do país do número de telefone no formato `+XXX` (ex.: `+507` para o Panamá, `+1` para os Estados Unidos). Deve corresponder ao formato `+` seguido de 1 a 3 dígitos |
| `type` | string | Yes | Tipo de validação. Deve ser um de: `validation`, `login`, `onboarding` ou `oneTimeLink` |
| `expiresAt` | string | No | Data de expiração opcional para o código de validação. Se não for fornecida, um tempo de expiração padrão será definido. Formato: ISO 8601 (ex.: `2024-12-31T23:59:59.000Z`) |
| `redirectUrl` | string | No | URL opcional para redirecionamento após a validação |
| `webhookUrl` | string | No | URL de webhook opcional para notificações de validação |
| `identityUrl` | string | No | URL opcional de verificação de identidade |
| `requires2FA` | boolean | No | Flag opcional que indica se a autenticação de dois fatores é necessária. O padrão é `false` |
| `ipAddress` | string | No | Endereço IP opcional do usuário |

#### Valores de Validation Method

| Value | Description |
| --- | --- |
| `verificationCode` | Envia uma senha de uso único (OTP) ao número de telefone para verificação |

#### Valores de Type

| Value | Description |
| --- | --- |
| `onboarding` | Verificação de telefone durante o cadastro do usuário (recomendado para app registrations) |
| `validation` | Validação geral de número de telefone |
| `login` | Verificação de telefone durante o login do usuário |
| `oneTimeLink` | Validação por link de uso único |

### Observações

- **Formato do Country Code**: O `countryCode` deve estar no formato `+XXX`, em que X são dígitos (máximo de 1 a 3 dígitos). Por exemplo: `+1`, `+507`, `+52`.
- **Número de telefone**: Espaços nos números de telefone são removidos automaticamente durante o processamento.
- **Segurança do OTP**: O OTP é criptografado com bcrypt antes do armazenamento, por segurança.
- **Gateway padrão**: As validações de telefone usam WhatsApp como método de entrega padrão, com base na configuração do fluxo do projeto.
- **Vinculação automática**: Quando criada pelo endpoint de app-registration, a validação de telefone é vinculada automaticamente ao registro de app registration do usuário.
- **Cobrança de créditos**: Este endpoint cobra automaticamente créditos do seu plano SmartEnroll.
- **App Registration obrigatório**: Este endpoint exige uma sessão ativa de app registration. Você deve usar o token retornado ao criar um App Registration.
