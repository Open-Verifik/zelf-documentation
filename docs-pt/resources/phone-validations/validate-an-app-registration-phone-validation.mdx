### Endpoint

```
PUT https://api.verifik.co/v2/phone-validations
```

Este endpoint valida uma senha de uso único (OTP) enviada ao número de telefone de um usuário durante o processo de app registration (onboarding). Ele garante que o OTP informado pelo usuário está correto e atualiza o status de verificação de acordo. Esta rota é projetada especificamente para usuários que estão no meio de um fluxo de app registration.

:::warning
O token JWT que você deve usar ao validar `App Registration Phone Validations` é fornecido na criação do `App Registration`. Você deve usar o token retornado ao criar um [App Registration](https://docs.verifik.co/resources/app-registrations/create-an-app-registration) para autenticar esta requisição.
:::

### Headers

| Name | Value |
| --- | --- |
| Content-Type | `application/json` |
| Authorization | `Bearer <token>` |

### Params

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `phone` | string | Yes | O número de telefone usado para criar a validação de telefone. Espaços serão removidos automaticamente durante o processamento |
| `countryCode` | string | Yes | O código do país do número de telefone no formato `+XXX` (ex.: `+507` para o Panamá, `+1` para os Estados Unidos). Deve corresponder ao formato `+` seguido de 1 a 3 dígitos |
| `otp` | number | Yes | A senha de uso único (OTP) que foi enviada ao número de telefone do usuário |
| `project` | string | No | O identificador único do projeto. Opcional, ajuda a restringir a validação |
| `projectFlow` | string | No | O identificador único do fluxo de projeto. Opcional, ajuda a restringir a validação |
| `phoneGateway` | string | No | O método de entrega usado: `sms`, `whatsapp` ou `none` |

### Observações

- **Fluxo de onboarding**: Este endpoint é projetado especificamente para usuários no processo de app registration, em que a validação de telefone faz parte da jornada de onboarding.
- **Expiração do OTP**: Os OTPs têm vida útil limitada (normalmente 10 minutos) e expiram após o tempo predefinido. OTPs expirados não podem ser validados.
- **Atualizações de status**: A validação bem-sucedida atualiza automaticamente o status da validação de telefone para "validated" e pode acionar etapas adicionais de onboarding.
- **Eventos de webhook**: Eventos de validação disparam notificações de webhook para rastreamento e integração.
- **Face Liveness**: Alguns fluxos de projeto podem recomendar verificação de face liveness após a validação de telefone como parte do processo de onboarding.
- **Vinculação ao App Registration**: Quando validada por este endpoint, a validação de telefone é vinculada automaticamente ao registro de app registration do usuário.
- **Formatação do número de telefone**: Espaços nos números de telefone são removidos automaticamente durante o processamento.
- **Formato do Country Code**: O código do país deve estar no formato `+XXX`, em que X são dígitos (máximo de 1 a 3 dígitos).
