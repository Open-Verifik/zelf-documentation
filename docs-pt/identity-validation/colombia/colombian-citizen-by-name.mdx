# Colômbia — Consulta de cidadão por nome (SCCRC)

Consulte o registro civil de nascimento (**SCCRC**) da **Registraduría Nacional del Estado Civil** usando **nomes**, **sexo** e **data de nascimento**. Diferente de [cidadão colombiano por documento](/identity-validation/colombia/colombian-citizen), este endpoint é uma **consulta inversa** e pode retornar **várias correspondências**.

Use quando você conhece atributos de identidade pessoal, mas não o NUIP/CC, ou quando precisa confirmar possíveis resultados no registro antes de uma verificação por documento.

## O que esta API retorna

- **`matches`** — array de resultados do registro civil (zero ou mais)
- **`documentNumber`**, **`documentType`** — NUIP/CC quando presentes no registro
- **`firstName`**, **`lastName`**, **`fullName`**, **`arrayName`** — partes do nome
- **`sexo`**, **`serial`** — sexo e serial do registro civil
- **`oficina`** / **`expeditionPlace`**, **`fecha`** / **`dateOfBirth`** — quando o enriquecimento Detalle estiver disponível
- **`recordType`** — `REGISTRO CIVIL DE NACIMIENTO`
- Um wrapper de resposta Verifik **assinado**

## Referência da API

### Endpoint

```
GET https://api.verifik.co/v2/co/cedula/by-name
```

Use este endpoint quando precisar **encontrar candidatos do registro de nascimento por nome**. A mesma integração está disponível como **`POST`** com corpo JSON. **`GET`** usa **parâmetros de consulta** conforme mostrado abaixo.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| name | type | required | description | Examples |
| --- | --- | --- | --- | --- |
| `primerNombre` | string | yes | Primeiro nome | `MARIA` |
| `primerApellido` | string | yes | Primeiro sobrenome | `LOPEZ` |
| `sexo` | string | yes | Sexo conforme registrado. Permitidos: `MASCULINO`, `FEMENINO` (também `M` / `F`) | `FEMENINO` |
| `fecha` | string | yes | Data de nascimento em **`DD/MM/YYYY`** | `15/03/1990` |
| `segundoNombre` | string | no | Segundo nome | `ELENA` |
| `segundoApellido` | string | no | Segundo sobrenome | `GARCIA` |

## Recursos

- **Consulta inversa** no registro de nascimento **SCCRC** da Registraduría
- A resposta sempre tem a forma **`{ matches: [...] }`** (revise cada resultado)
- Segundo nome / sobrenome opcionais melhoram a precisão
- **GET** e **POST** compartilham o mesmo handler

## Casos de uso

- Recuperar possíveis candidatos de **NUIP/CC** a partir de nome + data de nascimento conhecidos
- Pré-selecionar solicitantes quando apenas dados biográficos estão disponíveis
- Conferir a ortografia do nome com resultados do registro civil

### Notes

- Sempre inspecione **`matches`**; consultas por nome podem retornar mais de uma pessoa.
- **`fecha`** deve ser **`DD/MM/YYYY`** (data de nascimento).
- **Sandbox:** consultas por nome mapeiam para perfis fixos com números de documento **`10000001`–`10000010`**. Valores de exemplo padrão: `MARIA` / `LOPEZ` / `FEMENINO` / `15/03/1990`.
- Problemas temporários de disponibilidade da fonte podem aparecer como **409** (`Endpoint_out_of_service`).
- Relacionado: [Cidadão colombiano por documento](/identity-validation/colombia/colombian-citizen), [Registro civil por serial](/identity/colombia-registraduria-serial), [Registro civil de casamento](/identity/colombia-registraduria-matrimonio).
