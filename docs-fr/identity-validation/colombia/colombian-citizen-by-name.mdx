# Colombie — Recherche de citoyen par nom (SCCRC)

Interrogez le registre civil de naissance (**SCCRC**) de la **Registraduría Nacional del Estado Civil** à l’aide des **noms**, du **sexe** et de la **date de naissance**. Contrairement à [citoyen colombien par document](/identity-validation/colombia/colombian-citizen), cet endpoint est une **recherche inverse** et peut renvoyer **plusieurs correspondances**.

Utilisez-le lorsque vous connaissez des attributs d’identité personnelle mais pas le NUIP/CC, ou lorsque vous devez confirmer d’éventuels résultats du registre avant une vérification par document.

## Ce que renvoie cette API

- **`matches`** — tableau des résultats du registre civil (zéro ou plus)
- **`documentNumber`**, **`documentType`** — NUIP/CC lorsqu’ils sont présents sur l’acte
- **`firstName`**, **`lastName`**, **`fullName`**, **`arrayName`** — parties du nom
- **`sexo`**, **`serial`** — sexe et serial du registre civil
- **`oficina`** / **`expeditionPlace`**, **`fecha`** / **`dateOfBirth`** — lorsque l’enrichissement Detalle est disponible
- **`recordType`** — `REGISTRO CIVIL DE NACIMIENTO`
- Un wrapper de réponse Verifik **signé**

## Référence API

### Endpoint

```
GET https://api.verifik.co/v2/co/cedula/by-name
```

Utilisez cet endpoint lorsque vous devez **trouver des candidats du registre de naissance par nom**. La même intégration est disponible en **`POST`** avec un corps JSON. **`GET`** utilise des **paramètres de requête** comme indiqué ci-dessous.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| name | type | required | description | Examples |
| --- | --- | --- | --- | --- |
| `primerNombre` | string | yes | Premier prénom | `MARIA` |
| `primerApellido` | string | yes | Premier nom de famille | `LOPEZ` |
| `sexo` | string | yes | Sexe tel qu’enregistré. Autorisés : `MASCULINO`, `FEMENINO` (aussi `M` / `F`) | `FEMENINO` |
| `fecha` | string | yes | Date de naissance au format **`DD/MM/YYYY`** | `15/03/1990` |
| `segundoNombre` | string | no | Deuxième prénom | `ELENA` |
| `segundoApellido` | string | no | Deuxième nom de famille | `GARCIA` |

## Fonctionnalités

- **Recherche inverse** dans le registre de naissance **SCCRC** de la Registraduría
- La réponse est toujours structurée en **`{ matches: [...] }`** (examinez chaque résultat)
- Le deuxième prénom / nom de famille optionnels améliorent la précision
- **GET** et **POST** partagent le même handler

## Cas d’usage

- Récupérer d’éventuels candidats **NUIP/CC** à partir d’un nom + date de naissance connus
- Présélectionner des demandeurs lorsque seules des données biographiques sont disponibles
- Contrôler l’orthographe du nom par rapport aux résultats du registre civil

### Notes

- Inspectez toujours **`matches`** ; les requêtes par nom peuvent renvoyer plus d’une personne.
- **`fecha`** doit être au format **`DD/MM/YYYY`** (date de naissance).
- **Sandbox :** les requêtes par nom correspondent à des profils fixes avec les numéros de document **`10000001`–`10000010`**. Valeurs d’exemple par défaut : `MARIA` / `LOPEZ` / `FEMENINO` / `15/03/1990`.
- Des problèmes temporaires de disponibilité de la source peuvent apparaître en **409** (`Endpoint_out_of_service`).
- Voir aussi : [Citoyen colombien par document](/identity-validation/colombia/colombian-citizen), [Registre civil par serial](/identity/colombia-registraduria-serial), [Registre civil de mariage](/identity/colombia-registraduria-matrimonio).
