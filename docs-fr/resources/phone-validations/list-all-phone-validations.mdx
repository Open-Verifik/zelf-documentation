### Endpoint

```
GET https://api.verifik.co/v2/phone-validations
```

Ce service récupère une liste de toutes les validations téléphoniques avec filtrage et pagination optionnels. Vous pouvez filtrer par projet, statut, type et d'autres paramètres pour trouver des validations téléphoniques spécifiques.

#### Headers

#### `Content-Type`

**Type:** String  
**Required:** Required  
**Value:** `application/json`

#### `Authorization`

**Type:** String  
**Required:** Required  
**Value:** `Bearer {YOUR_ACCESS_TOKEN}`

#### Query Parameters

#### `page`

**Type:** Number  
**Required:** No

Numéro de page pour la pagination (défaut : 1).

#### `limit`

**Type:** Number  
**Required:** No

Nombre d'enregistrements par page (défaut : 10, max : 100).

#### `project`

**Type:** String  
**Required:** No

Filtrer par ID de projet.

#### `status`

**Type:** String  
**Required:** No

Filtrer par statut : `new`, `sent`, `validated`, `failed`.

#### `type`

**Type:** String  
**Required:** No

Filtrer par type : `validation`, `login`, `onboarding`.

#### `countryCode`

**Type:** String  
**Required:** No

Filtrer par indicatif pays.

#### `phone`

**Type:** String  
**Required:** No

Filtrer par numéro de téléphone.

#### `populates[]`

**Type:** String  
**Required:** No

Tableau optionnel de données associées à inclure. Options disponibles : `client`, `project`, `projectFlow`.

## Fonctionnalités

- **Liste complète** : Récupère toutes les validations téléphoniques de votre compte
- **Pagination** : Prise en charge de la pagination avec contrôle de page et de limite
- **Filtrage avancé** : Filtrer par projet, statut, type, indicatif pays et numéro de téléphone
- **Population des données** : Inclure des informations associées telles que les données client et projet
- **Plusieurs états** : Filtrer par statut (new, sent, validated, failed)
- **Indicatifs pays** : Filtrage spécifique par indicatif international
- **Plusieurs langages** : Prise en charge de JavaScript, Python, PHP et Swift
- **Informations détaillées** : Inclut les tentatives, limites et horodatages de validation
