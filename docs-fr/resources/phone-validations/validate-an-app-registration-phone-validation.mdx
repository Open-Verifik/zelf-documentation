### Endpoint

```
PUT https://api.verifik.co/v2/phone-validations
```

Cet endpoint valide un mot de passe à usage unique (OTP) envoyé au numéro de téléphone d'un utilisateur lors du processus d'enregistrement d'application (onboarding). Il s'assure que l'OTP fourni par l'utilisateur est correct et met à jour le statut de vérification en conséquence. Cette route est spécifiquement conçue pour les utilisateurs qui sont au milieu d'un flux d'enregistrement d'application.

:::warning
Le jeton JWT à utiliser lors de la validation des `App Registration Phone Validations` est fourni lors de la création de l'`App Registration`. Vous devez utiliser le jeton renvoyé lors de la création d'un [App Registration](https://docs.verifik.co/resources/app-registrations/create-an-app-registration) pour authentifier cette requête.
:::

### Headers

| Name | Value |
| --- | --- |
| Content-Type | `application/json` |
| Authorization | `Bearer <token>` |

### Params

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `phone` | string | Yes | Le numéro de téléphone utilisé pour créer la validation téléphonique. Les espaces seront automatiquement supprimés lors du traitement |
| `countryCode` | string | Yes | L'indicatif du numéro de téléphone au format `+XXX` (ex. `+507` pour le Panama, `+1` pour les États-Unis). Doit correspondre au format `+` suivi de 1 à 3 chiffres |
| `otp` | number | Yes | Le mot de passe à usage unique (OTP) qui a été envoyé au numéro de téléphone de l'utilisateur |
| `project` | string | No | L'identifiant unique du projet. Optionnel, aide à affiner la validation |
| `projectFlow` | string | No | L'identifiant unique du flux de projet. Optionnel, aide à affiner la validation |
| `phoneGateway` | string | No | La méthode de livraison utilisée : `sms`, `whatsapp`, ou `none` |

### Notes

- **Flux d'onboarding** : Cet endpoint est spécifiquement conçu pour les utilisateurs en cours d'enregistrement d'application, où la validation téléphonique fait partie du parcours d'onboarding.
- **Expiration de l'OTP** : Les OTP ont une durée de vie limitée (typiquement 10 minutes) et expirent après le délai prédéfini. Les OTP expirés ne peuvent pas être validés.
- **Mises à jour de statut** : Une validation réussie met automatiquement à jour le statut de la validation téléphonique à « validated » et peut déclencher des étapes d'onboarding supplémentaires.
- **Événements webhook** : Les événements de validation déclenchent des notifications webhook à des fins de suivi et d'intégration.
- **Face Liveness** : Certains flux de projet peuvent recommander une vérification de vivacité faciale après la validation téléphonique dans le cadre du processus d'onboarding.
- **Liaison App Registration** : Lorsqu'elle est validée via cet endpoint, la validation téléphonique est automatiquement liée à l'enregistrement d'application de l'utilisateur.
- **Formatage du numéro** : Les espaces dans les numéros de téléphone sont automatiquement supprimés lors du traitement.
- **Format de l'indicatif** : L'indicatif doit être au format `+XXX` où X sont des chiffres (1 à 3 chiffres maximum).
