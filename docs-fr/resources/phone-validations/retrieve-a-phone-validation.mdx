### Endpoint

```
GET https://api.verifik.co/v2/phone-validations/{id}
```

Ce service récupère un enregistrement de validation téléphonique spécifique à l'aide de son identifiant unique. La réponse inclut tous les détails du processus de validation téléphonique, y compris le statut, les informations OTP et les données de projet associées. Cet endpoint est utile pour vérifier le statut actuel d'une validation téléphonique ou récupérer des détails à des fins d'audit.

#### Headers

#### `Content-Type`

**Type:** String  
**Required:** Required  
**Value:** `application/json`

#### `Authorization`

**Type:** String  
**Required:** Required  
**Value:** `Bearer {YOUR_ACCESS_TOKEN}`

#### Path Parameters

#### `id`

**Type:** String  
**Required:** Yes

L'identifiant unique de la Phone Validation que vous souhaitez récupérer.

#### Query Parameters

#### `populates[]`

**Type:** String  
**Required:** No

Optionnel. Une liste d'objets liés à inclure dans la réponse. Options disponibles : `client`, `project`, `projectFlow`.

## Fonctionnalités

- **Récupération par ID** : Obtenez une validation téléphonique spécifique à l'aide de son ID unique
- **Informations complètes** : Inclut tous les détails du processus de validation
- **Données associées** : Informations sur le client, le projet et le flux de projet
- **Statut détaillé** : Statut actuel, tentatives, limites et horodatages
- **Configuration** : URL de redirection, webhooks et configurations de sécurité
- **Indicatifs pays** : Informations complètes sur l'indicatif et le numéro
- **Plusieurs langages** : Prise en charge de JavaScript, Python, PHP et Swift
- **Gestion des erreurs** : Réponses d'erreur détaillées pour différents scénarios
