### Endpoint

```
POST https://api.verifik.co/v2/phone-validations/app-registration
```

Une Phone Validation est une instance dans le système Verifik qui vous permet de traiter et de valider des numéros de téléphone lors du processus d'enregistrement d'application. Ce processus garantit l'authenticité des numéros de téléphone des utilisateurs et fournit une vérification sécurisée via SMS ou WhatsApp.

:::warning
Le jeton JWT à utiliser lors de la création des `App Registration Phone Validations` est fourni lors de la création de l'`App Registration`. Vous devez utiliser le jeton renvoyé lors de la création d'un [App Registration](https://docs.verifik.co/resources/app-registrations/create-an-app-registration) pour authentifier cette requête.
:::

### Headers

| Name | Value |
| --- | --- |
| Content-Type | `application/json` |
| Authorization | `Bearer <token>` |

### Params

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `project` | string | Yes | L'identifiant unique du projet où cette validation téléphonique sera utilisée |
| `validationMethod` | string | Yes | La méthode de validation. Doit être `verificationCode` |
| `phone` | string | Yes | Le numéro de téléphone qui sera validé. Les espaces seront automatiquement supprimés lors du traitement |
| `countryCode` | string | Yes | L'indicatif du numéro de téléphone au format `+XXX` (ex. `+507` pour le Panama, `+1` pour les États-Unis). Doit correspondre au format `+` suivi de 1 à 3 chiffres |
| `type` | string | Yes | Type de validation. Doit être l'un de : `validation`, `login`, `onboarding`, ou `oneTimeLink` |
| `expiresAt` | string | No | Date d'expiration optionnelle pour le code de validation. Si elle n'est pas fournie, une durée d'expiration par défaut sera définie. Format : ISO 8601 (ex. `2024-12-31T23:59:59.000Z`) |
| `redirectUrl` | string | No | URL optionnelle de redirection après validation |
| `webhookUrl` | string | No | URL de webhook optionnelle pour les notifications de validation |
| `identityUrl` | string | No | URL optionnelle de vérification d'identité |
| `requires2FA` | boolean | No | Indicateur optionnel précisant si l'authentification à deux facteurs est requise. Par défaut `false` |
| `ipAddress` | string | No | Adresse IP optionnelle de l'utilisateur |

#### Valeurs de Validation Method

| Value | Description |
| --- | --- |
| `verificationCode` | Envoie un mot de passe à usage unique (OTP) au numéro de téléphone pour vérification |

#### Valeurs de Type

| Value | Description |
| --- | --- |
| `onboarding` | Vérification téléphonique lors de l'inscription utilisateur (recommandé pour les app registrations) |
| `validation` | Validation générale du numéro de téléphone |
| `login` | Vérification téléphonique lors de la connexion utilisateur |
| `oneTimeLink` | Validation par lien à usage unique |

### Notes

- **Format de l'indicatif** : Le `countryCode` doit être au format `+XXX` où X sont des chiffres (1 à 3 chiffres maximum). Par exemple : `+1`, `+507`, `+52`.
- **Numéro de téléphone** : Les espaces dans les numéros de téléphone sont automatiquement supprimés lors du traitement.
- **Sécurité de l'OTP** : L'OTP est chiffré avec bcrypt avant le stockage pour des raisons de sécurité.
- **Passerelle par défaut** : Les validations téléphoniques utilisent par défaut WhatsApp selon la configuration de votre flux de projet.
- **Liaison automatique** : Lorsqu'elle est créée via l'endpoint app-registration, la validation téléphonique est automatiquement liée à l'enregistrement d'application de l'utilisateur.
- **Facturation des crédits** : Cet endpoint débite automatiquement des crédits de votre plan SmartEnroll.
- **App Registration requis** : Cet endpoint nécessite une session d'enregistrement d'application active. Vous devez utiliser le jeton renvoyé lors de la création d'un App Registration.
