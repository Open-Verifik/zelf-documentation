# Colombie — Registre civil de mariage (SCCRC)

Interrogez le **registre civil de mariage** (*registro civil de matrimonio*) de la **Registraduría Nacional del Estado Civil** (**SCCRC**).

Fournissez **un** mode de recherche :

1. **`documentNumber` + `sexo`** — recherche par document (un seul enregistrement)
2. **`primerNombre` + `primerApellido` + `sexo` + `fecha`** — recherche par nom (peut renvoyer **`matches`**)
3. **`serial`** — recherche par serial (un seul enregistrement)

## Ce que renvoie cette API

- Un seul enregistrement **ou** un tableau **`matches`** (mode nom)
- **`documentNumber`**, **`documentType`**, noms, **`sexo`**, **`serial`**
- **`oficina`** / **`expeditionPlace`**, **`fecha`** lorsqu’ils sont disponibles
- **`recordType`** — `REGISTRO CIVIL DE MATRIMONIO`
- Un wrapper de réponse Verifik **signé**

## Référence API

### Endpoint

```
GET https://api.verifik.co/v2/co/registraduria/matrimonio
```

Utilisez cet endpoint pour les consultations du **registre de mariage**. La même intégration est disponible en **`POST`** avec un corps JSON. **`GET`** utilise des **paramètres de requête** comme indiqué ci-dessous.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| name | type | required | description | Examples |
| --- | --- | --- | --- | --- |
| `documentNumber` | string | conditional | NUIP/CC ; nécessite **`sexo`** | `10000001` |
| `sexo` | string | conditional | Requis pour la recherche par document ou par nom (`MASCULINO` / `FEMENINO`) | `MASCULINO` |
| `serial` | string | conditional | Serial du registre de mariage | `0042012345` |
| `primerNombre` | string | conditional | Premier prénom (mode nom) | `JUAN` |
| `primerApellido` | string | conditional | Premier nom de famille (mode nom) | `PEREZ` |
| `fecha` | string | conditional | Date de mariage **`DD/MM/YYYY`** (mode nom) | `20/06/2015` |
| `segundoNombre` | string | no | Deuxième prénom | `CARLOS` |
| `segundoApellido` | string | no | Deuxième nom de famille | `GOMEZ` |

## Fonctionnalités

- Trois modes de recherche : **document**, **nom** ou **serial**
- Le mode nom peut renvoyer **`matches`** ; document/serial renvoient un seul objet
- **GET** et **POST** partagent le même handler

## Cas d’usage

- Confirmer un résultat du **registre de mariage** pour le KYC / la conformité
- Résoudre des serials de mariage liés à un document connu
- Filtrage par nom lorsque seules des données biographiques sont disponibles

### Notes

- Fournissez **exactement un** mode de recherche (ne mélangez pas serial avec les champs document/nom).
- **Sandbox :** numéros de document **`10000001`–`10000010`** ; le mode nom suit les mêmes profils sandbox que [par nom](/identity-validation/colombia/colombian-citizen-by-name).
- Des problèmes temporaires de disponibilité de la source peuvent apparaître en **409** (`Endpoint_out_of_service`).
- Voir aussi : [Citoyen par document](/identity-validation/colombia/colombian-citizen), [Citoyen par nom](/identity-validation/colombia/colombian-citizen-by-name), [Registre civil par serial](/identity/colombia-registraduria-serial), [Certificat Registraduría](/identity/colombia-registraduria-certificate).
