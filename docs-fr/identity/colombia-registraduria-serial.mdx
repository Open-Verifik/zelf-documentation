# Colombie — Consultation du registre civil par serial (SCCRC)

Localisez un acte de **naissance** du registre civil (*registro civil de nacimiento*) de la **Registraduría Nacional del Estado Civil** (**SCCRC**) à l’aide du **serial** imprimé sur le document du registre.

Cela complète [citoyen par document](/identity-validation/colombia/colombian-citizen) et [recherche par nom](/identity-validation/colombia/colombian-citizen-by-name) lorsque vous disposez déjà du serial du registre civil.

## Ce que renvoie cette API

- **`documentNumber`**, **`documentType`** — NUIP/CC lorsqu’ils sont présents
- **`firstName`**, **`lastName`**, **`fullName`**, **`arrayName`**
- **`sexo`**, **`serial`**
- **`oficina`** / **`expeditionPlace`**, **`fecha`** / **`dateOfBirth`** lorsqu’ils sont disponibles
- **`recordType`** — `REGISTRO CIVIL DE NACIMIENTO`
- Un wrapper de réponse Verifik **signé**

## Référence API

### Endpoint

```
GET https://api.verifik.co/v2/co/registraduria/serial
```

Utilisez cet endpoint lorsque vous avez le **serial du registre civil** et avez besoin des champs d’identité associés. La même intégration est disponible en **`POST`** avec un corps JSON. **`GET`** utilise des **paramètres de requête** comme indiqué ci-dessous.

### Headers

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### Parameters

| name | type | required | description | Examples |
| --- | --- | --- | --- | --- |
| `serial` | string | yes | Serial du registre civil (jusqu’à **10** chiffres ; zéros initiaux autorisés) | `0031058170` |

## Fonctionnalités

- Recherche par **serial** imprimé sur le *registro civil de nacimiento*
- Réponse à un seul enregistrement (pas un tableau `matches`)
- **GET** et **POST** partagent le même handler

## Cas d’usage

- Numériser ou valider des données d’un **registro civil** physique
- Résoudre un NUIP/CC à partir d’un serial de registre civil connu
- Pistes d’audit qui stockent des serials plutôt que des numéros de document

### Notes

- **`serial`** ne contient que des chiffres (le remplissage par zéros initiaux est accepté).
- **Serial d’exemple sandbox :** `0031058170` (correspond aux numéros de document sandbox dans la plage **`10000001`–`10000010`**).
- Des problèmes temporaires de disponibilité de la source peuvent apparaître en **409** (`Endpoint_out_of_service`).
