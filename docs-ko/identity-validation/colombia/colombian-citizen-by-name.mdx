# 콜롬비아 — 이름으로 시민 조회 (SCCRC)

**Registraduría Nacional del Estado Civil** 출생 민사등록부(**SCCRC**)를 **이름**, **성별**, **생년월일**로 검색합니다. [문서로 콜롬비아 시민 조회](/verifik-ko/identity-validation/colombia/colombian-citizen)와 달리 이 엔드포인트는 **역조회**이며 **여러 건**이 반환될 수 있습니다.

NUIP/CC는 모르지만 인적 속성을 알고 있거나, 문서 기반 확인 전에 등록부 후보를 확인해야 할 때 사용합니다.

## 이 API가 반환하는 내용

- **`matches`** — 민사등록 일치 결과 배열(0건 이상)
- **`documentNumber`**, **`documentType`** — 기록에 있을 때 NUIP/CC
- **`firstName`**, **`lastName`**, **`fullName`**, **`arrayName`** — 이름 구성 요소
- **`sexo`**, **`serial`** — 성별 및 민사등록 일련번호
- **`oficina`** / **`expeditionPlace`**, **`fecha`** / **`dateOfBirth`** — Detalle 보강이 가능할 때
- **`recordType`** — `REGISTRO CIVIL DE NACIMIENTO`
- **서명된** Verifik 응답 래퍼

## API 레퍼런스

### 엔드포인트

```
GET https://api.verifik.co/v2/co/cedula/by-name
```

**이름으로 출생 등록 후보를 찾을 때** 이 엔드포인트를 사용합니다. 동일한 연동은 JSON 본문의 **`POST`**로도 가능합니다. **`GET`**은 아래와 같이 **쿼리 매개변수**를 사용합니다.

### 헤더(Headers)

| Name | Value |
| --- | --- |
| Accept | `application/json` |
| Authorization | `Bearer <token>` |

### 매개변수(Parameters)

| name | type | required | description | Examples |
| --- | --- | --- | --- | --- |
| `primerNombre` | string | yes | 첫 번째 이름 | `MARIA` |
| `primerApellido` | string | yes | 첫 번째 성 | `LOPEZ` |
| `sexo` | string | yes | 등록된 성별. 허용: `MASCULINO`, `FEMENINO` (`M` / `F`도 가능) | `FEMENINO` |
| `fecha` | string | yes | 생년월일 **`DD/MM/YYYY`** | `15/03/1990` |
| `segundoNombre` | string | no | 두 번째 이름 | `ELENA` |
| `segundoApellido` | string | no | 두 번째 성 | `GARCIA` |

## 기능

- Registraduría **SCCRC** 출생 등록부에 대한 **역조회**
- 응답은 항상 **`{ matches: [...] }`** 형태(모든 결과를 검토)
- 선택적 두 번째 이름/성으로 정확도 향상
- **GET**과 **POST**가 동일한 핸들러를 공유

## 사용 사례

- 알려진 이름 + 생년월일로 가능한 **NUIP/CC** 후보 복원
- 생체정보만 있을 때 신청자 사전 스크리닝
- 민사등록 일치 결과와 이름 철자 교차 확인

### 참고(Notes)

- 항상 **`matches`**를 확인하세요. 이름 조회는 한 명 이상을 반환할 수 있습니다.
- **`fecha`**는 **`DD/MM/YYYY`**(생년월일)여야 합니다.
- **샌드박스:** 이름 조회는 문서 번호 **`10000001`–`10000010`**의 고정 프로필에 매핑됩니다. 예제 기본값: `MARIA` / `LOPEZ` / `FEMENINO` / `15/03/1990`.
- 일시적인 소스 가용성 문제는 **409**(`Endpoint_out_of_service`)로 나타날 수 있습니다.
