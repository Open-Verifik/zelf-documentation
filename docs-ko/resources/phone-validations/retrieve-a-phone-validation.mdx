### Endpoint

```
GET https://api.verifik.co/v2/phone-validations/{id}
```

이 서비스는 고유 식별자를 사용해 특정 전화번호 검증 기록을 조회합니다. 응답에는 상태, OTP 정보, 연결된 프로젝트 데이터를 포함한 전화 검증 프로세스의 모든 세부 정보가 포함됩니다. 이 엔드포인트는 전화 검증의 현재 상태를 확인하거나 감사 목적으로 세부 정보를 조회할 때 유용합니다.

#### Headers

#### `Content-Type`

**Type:** String  
**Required:** Required  
**Value:** `application/json`

#### `Authorization`

**Type:** String  
**Required:** Required  
**Value:** `Bearer {YOUR_ACCESS_TOKEN}`

#### Path Parameters

#### `id`

**Type:** String  
**Required:** Yes

조회하려는 Phone Validation의 고유 식별자입니다.

#### Query Parameters

#### `populates[]`

**Type:** String  
**Required:** No

선택 사항. 응답에 포함할 관련 객체 목록입니다. 사용 가능한 옵션: `client`, `project`, `projectFlow`.

## Features

- **ID로 조회**: 고유 ID를 사용해 특정 전화 검증을 가져옵니다
- **완전한 정보**: 검증 프로세스의 모든 세부 정보를 포함합니다
- **관련 데이터**: 클라이언트, 프로젝트 및 프로젝트 플로우 정보
- **상세 상태**: 현재 상태, 시도 횟수, 한도 및 타임스탬프
- **구성**: 리디렉션 URL, 웹훅 및 보안 설정
- **국가 코드**: 전체 국가 코드 및 번호 정보
- **다중 언어**: JavaScript, Python, PHP 및 Swift 지원
- **오류 처리**: 다양한 시나리오에 대한 상세한 오류 응답
